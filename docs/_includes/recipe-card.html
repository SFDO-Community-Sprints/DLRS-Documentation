{%- comment -%} Renders one cookbook recipe (a document from the `recipes` collection) as a collapsible card. Usage: {% include recipe-card.html recipe=recipe %} The h2 id derives from the recipe's filename (its slug), so the filename is part of the recipe's public URL — never rename a published recipe file, or external deep links to it will break. Accessibility: the h2 carries class="no_anchor" so the theme does NOT inject its heading permalink icon here. That icon is a link, and a link inside the toggle can capture a screen reader's Enter key so the card can't be closed. no_anchor only suppresses the icon — the id stays, so #slug URLs still work. The "Link to this recipe" link in the opened body replaces the icon. {%- endcomment -%} {%- assign r = include.recipe -%} {%- comment -%} mode key/label both come from recipe-mode.html — the single source of truth for mode presentation (CSS class, chip shorthand, tooltip). {%- endcomment -%} {%- capture mkey -%}{%- include recipe-mode.html mode=r.mode -%}{%- endcapture -%} {%- capture mlabel -%}{%- include recipe-mode.html mode=r.mode out="label" -%}{%- endcapture -%} {%- capture olabel -%}{%- include recipe-op.html operation=r.operation out="label" -%}{%- endcapture -%}
