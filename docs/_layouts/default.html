Exactly one line differs from the theme: the anchor_headings include below, which adds the permalink icon link to every heading that has an id. The theme puts that link BEFORE the heading text and names it with aria-labelledby pointing at its own parent heading, so screen readers read every heading's text twice. Here the link comes AFTER the text (no beforeHeading) and has its own short aria-label instead. Cookbook recipe titles opt out of this link altogether (class="no_anchor"), because they sit inside a toggle — see _includes/recipe-card.html.
