--- layout: table_wrappers --- {%- comment -%} LOCAL OVERRIDE of the Just the Docs theme's _layouts/default.html, copied from the v0.12.0 release (the tag pinned as remote_theme in _config.yml). Exactly one line differs from the theme: the anchor_headings include below. The theme puts each heading's permalink icon BEFORE the heading text and names it with aria-labelledby pointing at its own parent heading. Screen readers then read every heading twice, and on cookbook recipe cards (where the heading sits inside the toggle) Enter lands on the link, not the toggle, so a card can be opened but never closed. Here the link comes AFTER the text (no beforeHeading) and has its own aria-label. Verified with NVDA.
